# PB9 USB 独立测试

用途：区分 PB9 输出端异常与功率板/排线负载异常。用户已确认主控可由 USB 独立供电。

1. 断开电池和 USB，拔掉整束主控—功率板排线，不必拆单根线。
2. 烧录 output/pb9_usb_test/PB9_USB_Test.hex，仅由 USB 给主控供电。
3. 示波器地接主控 GND，测 MCU PB9；DC 耦合、20μs/div，探头倍率与通道设置一致。
4. 测试镜像上电后持续输出约 25kHz、50% 占空比，不播放音乐、不显示 OLED，不运行机器人任务、四轮自检或 FG 速度环。
5. 接回功率板之前，先恢复正常 SRC_Firmware/SRC_Firmware.hex，再断电接线。

判断：空载恢复约0～3.3V，优先查排线、RN4、功率板输入及错接/短接；空载仍约2～3.3V，确认测量参考和倍率后，检查主控板本地连接与PB9输出级。不能仅凭后者就认定整颗MCU损坏。

正常5.1kΩ上拉至3.3V的拉低电流约0.65mA；正常推挽输出应能拉低。RN4阻值装错、焊桥或内部/焊盘连接异常则可能造成过重负载。断电、放电后在板测PWM5到3.3V阻值，与正常通道比较；并联路径可能使在板读数偏离5.1kΩ，异常时需隔离器件确认，不能仅凭蜂鸣判定。

生成工程：`python tests/build_pb9_usb_test.py`。生成的独立工程为 tmp/pb9_usb_test/PB9_USB_Test.uvprojx，Keil目标 PB9_USB_Test。它从当前主程序复制生成临时入口，并将源码路径转换为绝对路径；不会改正常 main.c、正常工程或正常固件输出。

测试入口保留原HAL时基和系统时钟，仅调用MX_TIM11_Init并设CCR1为(ARR+1)/2；不启动RTOS或电池/FG保护任务。该镜像是脱离功率板的台架测试镜像，不用于机器人运行。

若打开工程出现“ARM:CMSIS:4.5.0 / Pack not found”：新版生成器已去除独立测试工程中多余的旧CMSIS RTE选择，使用仓库自带CMSIS头文件，无需为此安装4.5.0。关闭旧测试工程时不要保存旧配置，再打开tmp/pb9_usb_test/PB9_USB_Test.uvprojx。正常工程的RTE设置保持原样；测试工程保留本机已安装的Keil.STM32F4xx_DFP.1.0.8设备包。
